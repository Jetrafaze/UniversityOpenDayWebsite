# University Open Day Website

A static website built for the university's Marketing Department to inform prospective students about the annual Open Day event, available academic faculties, admission guidelines, and contact details.

## Features
- Fully responsive layout across mobile and desktop devices
- Structured information on Science, Commerce, and Engineering faculties
- Clear admission requirements and application steps
- Interactive Google Maps embed on the Contact page

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub & GitHub Pages
